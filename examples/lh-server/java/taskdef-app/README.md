# TaskDef App

This example registers the greet TaskDef with the LittleHorse server.

## Prerequisites
- Java 21+
- A compatible LittleHorse Server running. See the shared [server setup](../../README.md#littlehorse-server-version).

## Run
From the repository root:

```sh
./gradlew :examples:lh-server:java:taskdef-app:run
```

From this directory:

```sh
../../../../gradlew :examples:lh-server:java:taskdef-app:run
```
