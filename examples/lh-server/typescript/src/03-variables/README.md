# Variables

This example demonstrates required and searchable workflow variables; assigning task output; mutating variables; formatting strings; and accessing JSON fields.

## Run

From `examples/lh-server/typescript`, start the application:

```bash
npm run variables
```

In another terminal:

```bash
lhctl run variables-example user-id obiwan
```

Keep the application running while the workflow executes, then stop it with `Ctrl+C`.
