## Server Compatibility Blocker

- The complete Arrays and Maps workflow cannot register on the tested `1.3.0-SNAPSHOT` server. The server rejects native-array membership generated by `numbers.doesContain(valueToCheck)` with `You cannot use LHS type INT with Comparator IN`.
- Reversing the operands with `numbers.isIn(valueToCheck)` is also rejected, with `You cannot compare RHS type INT using Comparator IN`.
- The same native-array `doesContain()` pattern exists in the server's Java `ArraysTest`, so this is a server validation gap rather than TypeScript task-worker behavior.
