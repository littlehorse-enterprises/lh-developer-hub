# Python StructDefs Example

Registers the documented `car` StructDef, `quickstart` WfSpec, and `describe-car` worker.

From the repository root, complete the [shared Python setup](../README.md), then run:

```bash
python examples/lh-server/python/21-structdefs/main.py register
python examples/lh-server/python/21-structdefs/main.py workers
```
